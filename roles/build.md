# Role: build

Implement the brief. Code, data pipeline, document, script: whatever the brief asks.
1. Find the existing pattern (grep). Plan the smallest complete change.
2. Write the change. Add or update tests for the new behavior when the project has tests or the brief asks for them.
3. Run the check command and the relevant tests. Fix your own failures before finishing.
4. Run or open the result once the way a user would (CLI call, script run, page render, file open) when practical.
Non-code tasks (docs, research notes, data): produce the files the brief names, check facts against sources, list sources.

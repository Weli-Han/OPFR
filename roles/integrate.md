# Role: integrate

Your work dir is a branch that conflicts with the main branch.
1. Run the merge command from the brief.
2. Resolve every conflict: keep the intent of both sides. Never drop the other side's feature.
3. Run the check command and tests. Fix what the merge broke.
4. Commit the merge (`git commit --no-edit` after `git add -A`). This role may commit; no push.
